# 💰 Smart Expense Tracker Web Application

An interactive, responsive web application built to help users log, categorize, analyze, and manage daily expenses efficiently.

## 🚀 Key Features
- **CRUD Operations:** Create, Read, Update, and Delete expense entries dynamically.
- **Data Visualization:** Interactive category pie charts and daily spending heatmaps powered by Chart.js.
- **Smart Insights:** Automatic calculation of average expense per entry, highest spending category, and monthly budget savings tracker.
- **Search & Filter:** Real-time filtering by category, date range (Today, Week, Month), and keyword search.
- **Data Export:** Instant download of expense history in CSV/Spreadsheet format.
- **Persistent Storage:** Utilizes browser LocalStorage to retain transaction data across sessions.

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data Visualization:** Chart.js Library
- **Storage:** Web Storage API (LocalStorage)

## 📸 Usage
1. Open `index.html` in any web browser.
2. Navigate to `tracker.html` to log new expenses or search through previous entries.
3. Click **View Charts** to inspect spending analytics on `chart.html`.
4. Click **Export to CSV** to save data locally.
